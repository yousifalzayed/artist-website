October 24–29, 2024 · Bogotá, Colombia

This piece uses spatial audio techniques, combined with video projection, to visualize a sound source as it moves across an array of multiple speakers. The movement of each sound source is mapped to a visual signifier such as a butterfly, such that when a butterfly moves closer to one speaker it gets louder. The animation of a butterfly is created using oscillograph techniques, which is a process that uses two sound inputs (x & y), to create an image in real-time. To modulate and move the image source around, the piece will include a microphone that audience members can use to interact with the piece.
